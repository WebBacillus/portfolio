# Portfolio

Terms used to describe the portfolio and its Job Matching experience.

## Language

**Job description**:
The role information a visitor supplies for a single Job Matching assessment. It describes the role, not the candidate.

**Job requirement**:
A distinct, independently assessable expectation about the candidate extracted from a job description. A list of separate skills yields separate requirements unless the role explicitly requires them together.

**Job match result**:
An explanation of each job requirement against approved candidate evidence, without a total score or hiring recommendation.
_Avoid_: Fit score, hiring verdict

**Evidence status**:
The result for one job requirement: **Has evidence**, **Partial evidence**, or **No evidence found**. The status describes documentation available to the chatbot, not the candidate's actual ability; **No evidence found** does not mean the candidate lacks the skill.

**Approved candidate evidence**:
Facts stated in the approved CV or a published project page. An About page fact may support an assessment only when it does not conflict with the CV.
_Avoid_: Visitor job description, private notes, unreviewed repository content

**Project contribution**:
The candidate's documented participation in a project. When a project uses a technology but the candidate's specific part is unstated, the supported claim is participation in a project that uses that technology.
