# Model access for the public portfolio chatbot

**Finding:** OpenAI's first-party API documentation lists **GPT-6 Luna** with the exact API model ID **`gpt-6-luna`** (the user's phrase was “gpt6 luna”; do not use that phrase itself as an API ID). It supports `v1/responses`, streaming and function calling; the model page says to use the **Responses API** for built-in tools and function calling. Chat Completions function calling is supported only with `reasoning_effort: none`. Listed Responses tools include web search, file search and MCP. This is a documented API route suitable in principle for a server-side, public-facing application, **not proof that this project's account can access it**. [GPT-6 Luna model card](https://developers.openai.com/api/docs/models/gpt-6-luna)

**Verification before deployment:** With a newly provisioned, authorized **API Platform project key** held only on the server, inspect the project's model availability in the [API dashboard](https://platform.openai.com/settings/organization/limits), call the documented [`GET /v1/models`](https://developers.openai.com/api/reference/resources/models/methods/list) and check whether its `data[].id` contains exactly `gpt-6-luna`, then make a minimal authenticated [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create) request with that documented ID (and test the intended tool). The model list documents currently available models; a successful real request is the stronger check of endpoint, project access, billing and tool behavior. No account-specific check or paid API request was made for this research; no credentials were inspected. [List models](https://developers.openai.com/api/reference/resources/models/methods/list) · [API authentication](https://developers.openai.com/api/reference/overview)

**Billing and containment:** API usage is billed separately from ChatGPT/Codex subscription usage. The published GPT-6 Luna Standard text rates are **$0.10/1M input tokens**, **$0.01/1M cached input tokens** and **$0.50/1M output tokens**; tool calls and processing modes may add cost. A dedicated API project, server-side key/secret management, application-level per-visitor rate limits and input/output limits are appropriate for anonymous traffic. Set a project monthly **hard spend limit** and earlier spend alerts; alerts alone do not stop traffic. A hard limit returns `429` and can slightly overshoot while enforcement propagates, so it is not an exact zero-overrun guarantee. The organization's approved usage limit and model rate limits are separate controls. [Model pricing and capabilities](https://developers.openai.com/api/docs/models/gpt-6-luna) · [Spend limits](https://developers.openai.com/api/docs/guides/spend-limits) · [Production best practices](https://developers.openai.com/api/docs/guides/production-best-practices) · [Rate limits](https://developers.openai.com/api/docs/guides/rate-limits)

**Do not repurpose Codex subscription credentials as the public site's provider auth.** OpenAI distinguishes ChatGPT-plan Codex usage from API-key usage, which follows API model availability and API pricing. Its Codex-auth automation guide says an API key is the right way to authenticate automation and confines reused ChatGPT-managed Codex auth to trusted private infrastructure; it explicitly says not to use that workflow for public or open-source repositories. This does **not** establish that every ChatGPT-plan integration is forbidden: OpenAI separately describes user-authorized access to eligible apps/sites, but that is not evidence of a supported shared subscription credential funding unauthenticated visitors. The private dashboard's experimental `gpt-5.6-luna` Codex route is neither the requested `gpt-6-luna` ID nor a substitute for an API entitlement check. [Codex pricing](https://developers.openai.com/codex/pricing) · [Codex CI/CD authentication](https://developers.openai.com/codex/auth/ci-cd-auth) · [ChatGPT plan in other apps/sites](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites)

**Unknowns:** This project's actual API billing status, accessible model list, rate tier, approved usage limit, available tools, and acceptable monthly budget have not been checked. A public endpoint still needs local abuse protections in addition to provider spend controls. This note makes no claim about contractual permission beyond the cited documentation; resolve any special subscription-auth arrangement with OpenAI before considering it.
